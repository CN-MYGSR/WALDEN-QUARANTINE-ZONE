# Escape from TakeFu（废城撤离）

基于 Three.js 的浏览器单局撤离射击原型（塔科夫式）。当前版本不含任何官方素材或商标资产。

# 世界观

> *「封锁线不会为你打开第二次。灯亮着，就走。」*
> ——渡鸦小队行动守则第一条

## 序章：瓦尔登的十一天

**瓦尔登（Walden）**，东欧边境一座四十七万人口的工业港城。它在地图上平凡得近乎透明，直到 1980 年代，华约工程兵在城下挖空了三层石灰岩，把它改造成代号 **「铁砧」（ANVIL）** 的地下储备枢纽——军械、生物制剂、以及一大批从来没有登记进任何一份清单的东西。

1991 年之后，铁砧被水泥封死，档案被销毁，城市回归平静。

2021 年，一家注册地横跨三块大陆的安保与生物医药联合体——**黑橡树（Nyxos–Blackwood Konsortium，圈内简称 NBK）**——拿下了瓦尔登老城区的"环境治理与城市更新"总包合同。他们的施工队打穿了铁砧的封层。

2024 年 3 月，老城北部一处封存冷库发生泄漏。官方通报写作"工业气体事故"。接下来的十一天里，供水中断、电网崩塌、治安瓦解，第 12 天凌晨，瓦尔登全城被划为 **隔离禁区（Quarantine Zone, QZ）**，居民疏散，边境关闭。

五年过去了。**现在是 2026 年。**

## 地理：铁砧区

你行动的区域是老城中心一块 **200 米见方** 的街区——坍塌的公寓楼、被弹坑撕开的马路、只剩骨架的厂房。这里没有电，没有水，没有信号，只有风穿过碎玻璃的声音，和不知道从哪扇窗户后面伸出来的枪管。

- **全图 14 个货箱**：NBK 撤退时来不及运走的集装箱，散落在街区内部与楼体旁。撬开哪一个，取决于你的运气。
- **地下设施入口**：部分楼房的地下室直通铁砧。这也是为什么这片街区里的东西值钱得离谱。
- **北港吊塔**：城市正北旧港区的一座龙门吊，顶上挂着一盏还在亮着的绿色信号灯。

## 势力

### 联合封锁部队 · 美军 / 德军

名义上，禁区由联合国框架下的联合封锁部队看管，美军与德军各出一支分队负责"清场"——清掉 NBK 的私人武装，销毁或收缴地下设施里的制剂与资料。

**问题在于：NBK 两边的合同都买了。**

美方怀疑德军在替 NBK 转移样本。德方怀疑美军在替 NBK 抢资料。双方的作战令写得一模一样，都要求"优先控制并销毁目标物，对阻碍者使用武力"。于是两支本该协同的正规军，在同一座废城里互相开火，谁都认为自己才是被出卖的那个。

**这就是为什么你在游戏里带着美军或德军的番号，却在打另一支正规军。**

### 黑橡树联合体（NBK）

没有国旗，没有制服，只有合同。NBK 的私人军事公司穿着和拾荒者差不多的便装，装备却比正规军还整齐——他们的任务从来不是打赢，是拖住。城里那 16 名敌方清场人员里，你分不清哪些是 NBK 的合同兵，哪些只是倒霉的拾荒者。**也没必要分清。**

### 拾荒者（Scav）

疏散时没走成的居民、被裁员的前施工队、从边境偷渡进来找东西的亡命徒。他们没有组织，只有地盘。他们对正规军开枪，对 NBK 开枪，也对彼此开枪——但你最常遇见他们的地方，是他们翻过的货箱旁边，尸体还是热的。

### 你：渡鸦小队

你带领一支 4 人小队从封锁线渗透进来，编号 **渡鸦（RAVEN）**。全城还有另外两支友军小队，各走各的，你也指挥不动他们。

你没有后援，没有身份，没有第二次机会。你的档案在进封锁线的那一刻就被删除了——这是接应方唯一肯提供的"保障"。城里 12 名友军是你唯一能指望的人，而他们中的大多数，撑不到窗口期结束。

## 为什么武器跨越三个世代

铁砧封存了四十年的军械，而 NBK 的仓库管理员从不分类，只按箱号堆放。

所以在这座废城里，你能从同一个货箱里翻出 **1943 年的 StG44 和 Kar98**、**冷战末期的 AK-74M 与莫辛纳甘**、以及 **M4、G36C、MP5 这些还带着出厂油的现代货**。能不能用，取决于枪管里有没有进灰；好不好用，取决于你愿意为一把好枪背多重的东西出去。

弹药同理——你手里那盒子弹，可能比你父亲年纪还大。

## 禁区经济学

封锁线以内，钱不算钱。**能被带出去的东西才算。**

| 类别 | 代表物 | 为什么值钱 |
|---|---|---|
| 硬通货 | 香烟、烈酒 | 禁区里唯一稳定的交易媒介，连拾荒者都认 |
| 身份证明 | 狗牌、信用卡、文件 | 外面有人愿意为"某人确实死在里面"付钱 |
| 工具 | 螺丝刀、扳手、五金件 | 城外重建用得上，永远缺 |
| 药品 | 抗生素、消毒液、医疗包 | 禁区里没有医院 |
| 电子垃圾 | 显卡、芯片、医疗记录仪、LEDX | 铁砧地下实验室的设备，黑市天价 |
| 门禁 | 钥匙卡、卫星电话、文件 | 能打开你打不开的门 |

封锁线外有三个买家：

- **军械库**：走私商，只认钱，什么都收，什么都不问。
- **市集**：黑市，收购价约为市价的 45%——他们承担风险，你承担差价。
- **改枪工坊**：拾荒者里的机械师，按件收费给你装消音器、瞄具、夜视仪。

**保险**是走私商提供的另一项服务：你付一笔钱，他们派人去你的尸体上把装备扒回来。成功率七成。剩下的三成，归拾荒者。

## 撤离与「撤离通行证」

**普通撤离**：任何地图的撤离点都能带走战利品，但只有**港口**的登船点能把人送出隔离禁区。

**「撤离通行证」本质上是一张船票**：完成全部 24 个任务后市集解锁购买，售价 ¥12000。持有它且从**港口**撤离，才算「离开瓦尔登隔离禁区」，结算画面会出现「重生」按钮，进入 NG+（任务目标提高、敌方更强、己方更弱）。

在**街区**或**秘密实验室**撤离时，即使背包里有通行证也**不会消耗**，也不算解锁结局——它只是瓦尔登港的船票。

## 撤离灯塔

北港那座龙门吊上的绿灯，原本是 NBK 给自家运输队做的导航灯。城市死了，灯还亮着——它接在一组独立太阳能和一组铅酸电池上，没人知道还能撑多久。

**灯不认人，只认信标。** 只要你在灯的光圈里站满 **6 秒**，接应方就放行。

但窗口期只有 **25 分钟**——那是封锁线外维和巡逻换班的间隙。过了这个点，接应方不会再等你，灯还亮着，但没人来了。

## 单命局

封锁线不会为你打开第二次。

你的小队进场后，不会再有新的增援。阵亡即任务失败：背包、携带装备全部留在城里（投保的部分有七成机会被回收，**回主菜单领取**），安全箱里的东西跟着你回来——那是你提前塞进衣服夹层里的，谁也拿不走。

# 核心玩法

1. **军械库**购买武器/防弹衣，**市集**交易食物/药品/杂物/背包/夜视仪，**改枪工坊**用货币安装配件。
2. **撤离部署**界面顶部的**地图卡片**列出全部地图（点卡片即选中该图，鼠标悬停看简报），然后选主/副武器、防弹衣、背包、最多 3 种医疗品、2 种食物，可为装备投保。**选中的地图与当前地图不同时，会自动切图并重新进入部署界面**；相同则直接开始。
3. 进入地图后：击杀敌人留下**尸体**，靠近物资箱按 `F` 打开搜刮面板，`↑/↓` 选择物品，`F` 拿取选中。
4. 留意**水分**与**保食度**两条状态条：归零会持续掉血。`K` 食用选中食物，`J` 切换食物。
5. 受伤后按 `H` 使用医疗品（按伤势自动选择：手术包→止痛药/吗啡→止血带→抗生素→医疗包→肾上腺素）。
6. **普通撤离**：抵达撤离点保持 6 秒完成撤离，带出战利品入库出售。只有从**港口**登船并持有「撤离通行证」才算真正离开隔离禁区，解锁结局与重生。
7. **单命局**：开局后不再有新人员进场；阵亡即撤离失败，背包与携带装备丢失（保险 70% 返还，回主菜单领取）。

## 任务

任务分两类：

- **通用任务（20 个）**：任何地图都能推进（使用/购买/击杀等）。
- **地图专属任务（各 4 个）**：只有在指定地图内发生的事件才计入进度。
  - **街区**：逐屋清剿等。
  - **秘密实验室**：`设施侦察`（搜索 10 件物资）· `净化协议`（击杀 14 名守备）· `样本回收`（带出 6 件稀有物资）· `活着出来`（成功撤离 1 次）。

稀有物资指：芯片 / 名表 / 卫星电话 / 文件 / 显卡 / 通行卡 / 医疗记录仪 / 夜视仪。


## 伤势与医疗

血量不再用血条表示，完全由左下角**人体状态图**呈现，七个部位按伤势着色：

| 颜色 | 含义 |
|---|---|
| 白 | 满血 |
| 黄 | 轻伤到中伤 |
| 红 | 重伤 |
| 黑 | 严重重伤 / 已报废 |

鼠标悬停在部位上可以看到精确血量。除了掉血，你还会**出血**、**骨折**、**肢体报废**——出血不止住会持续掉血直到死亡，骨折拖慢行动，报废的肢体必须靠手术包才能恢复。

**止痛药**与**吗啡**不只是止痛：

| | 止痛药（180 秒） | 吗啡（300 秒） |
|---|---|---|
| 止痛 | 消除疼痛带来的手抖与腿软 | 同左，且四肢恢复 15 点 |
| 暂缓扣血 | 失血速度 ×0.65 | 失血速度 ×0.52 |
| 移速 | +11% | +19% |
| 准度 | 散布 −22% | 散布 −37% |

未止痛时，只要处于骨折、重度出血、肢体报废或任一部位见底的状态，就会持续疼痛：移速 ×0.9、散布 ×1.3。

## 经济与平衡

- 初始作战货币 2,600，新手物资：轻便挎包、医疗包、止血带、止痛药、矿泉水×2、方便面。
- 所有消耗品（药品 1 份 / 食物 1 份）在部署时从仓库扣除；死亡丢失主/副武器与防弹衣（可投保）。
- 市集收购价统一为市价的 45%；杂物从香烟(¥210)到医疗记录仪(¥3,200)分 5 档稀有度。
- 改枪工坊按件收取改装费（消音器 ¥560、4 倍镜 ¥720 等），局外改枪整局生效；夜视仪(¥2,200)需持有并在工坊装入『战术配件』槽，仅夜战可用、阵亡丢失。
- 收益参考：单箱约 ¥880、单尸约 ¥760（出售价），背包 10–24 格与负重减速限制实际带出量。

## 操作

- `WASD` 移动，`Shift` 疾跑，`空格` 跳，`C` 蹲，`Z` 趴，`X` 架枪，`Q/E` 侧身
- 鼠标左键射击，右键机瞄，`R` 装填，`1/2` 切枪，`V` 近战
- 鼠标滚轮切换高低姿态持枪（低位持枪移速更快、散布更大）
- `G` 手雷，`3` AT雷，`4` 烟雾弹
- `H` 用药（按伤势自动选择），`K` 进食/喝水，`J` 换食物，`N` 夜视仪
- `L` 切换「开镜隐藏枪身」（默认关：看得见枪；打开后由准星接管瞄准）
- `F` 互动：搜尸/物资箱（`↑/↓` 选择 · `F` 拿取选中）/机枪/迫击炮/补给；撤离点保持站立
- `Tab` 打开背包（可丢弃物资），`T/U/Y` 小队指令，`M` 大地图

## 阵亡反馈

阵亡时不再只是黑屏 + 一句名言，会明确告诉你「是谁、用什么、打在哪、多远」：

- **击杀提示**（死亡瞬间，屏幕上方）：凶手 + 阵营 · **命中部位**（头部 / 躯干 / 手臂 / 腿部，头部额外标「爆头」）· 武器 · 距离 · 致命伤，以及**本局受击明细**（被哪个部位打中几次、各累计多少伤害）。
- **敌方回放**（阵亡后约 2.2 秒）：从**开枪者视角**重放致死前的最后两秒多 —— 能看清自己是被架住、被绕后还是被远距离点名。常态以 12Hz 记录"当前最值得跟拍的敌人"（优先最近打过你的人，否则最近的敌人），所以**被一枪秒杀时也有素材可放**；素材不足时自动退回原本的布娃娃死亡视角。
- **死亡分析**（结算界面持久显示）：死亡视角只有两秒多，来不及看清，所以结算页会把凶手 / 武器 / 距离 / 致命部位 / 剩余血量 / 各部位受击统计再完整列一遍。

**开镜挡视野的修复**：真正的病因是 **ADS 视模型离 vmCamera 太近** —— 后照门、枪机、枪托这些低模几何被透视放大，糊成挡住屏幕中央的一大块。

- 只沿 z 轴把整枪往前推：基础推远量加大（步枪 0.30 / 反坦克枪 0.22 / 火箭筒 0.16，装了非机瞄光学件再 +0.06），**不移动世界相机**，所以准星投影恒在屏幕中心，不会造成准星偏移。
- 换枪时按实测包围盒算一次净空要求：只统计**会落进屏幕中央视野走廊**的部件（±0.06 的横竖走廊，且按 ADS 姿态的横竖偏移换算），保证这些部件离镜头 **不少于 0.28 m**；取"基础推远量"与"净空要求"里更远的一个作为 ADS 稳态深度。这样长枪的枪托（本来就贴着腮帮子、且不在中央视野里）不会把整枪推到看不清准星，而真正会挡中央的部件则被硬性挡住。
- 该约束只作用于开镜稳态、且跳过光学镜（镜筒本来就该贴到眼前，之后由 `scopeOv` 接管）。
- 另有兜底与可选开关：开镜时视模型相机的近裁剪面抬到 0.05，把残余"糊在镜头前"的几何直接裁掉；按 **`L`** 可在开镜时隐藏枪身（默认**不隐藏**，隐藏时自动用准星接管瞄准）。

**视野 FOV 可调**：设置界面新增「视野 FOV」滑杆（60–100，默认 74）。开镜 FOV 按同比例缩放，所以调整它只改视野广度、**不改变开镜倍率**；滑杆值即时生效并存入本地。
