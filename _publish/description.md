# 撤离瓦尔登（Escape from TakeFu）

浏览器里直接开打的塔科夫式单局撤离射击原型（Three.js），打开即玩。

## 玩法

你是被丢进瓦尔登隔离禁区的雇佣兵。目标只有两个：**搜刮值钱的东西，活着走到撤离点**。死了，带进去的一切都没了。

- **搜刮**：地图里散布货箱、尸体和报关货物。撬箱、拾取、塞进背包，注意格数与负重
- **撤离**：站进撤离点读条完成即可带出战利品。中途阵亡 = 本局收益归零。**每局只有 5 分钟**。
- **港口通行证**：完成全部任务后可在市集买到「撤离通行证」——瓦尔登港的**船票**。必须**出击前放进装备槽随身带上**并在港口登船撤离，才算真正离开禁区（解锁结局与重生）。登船消耗，阵亡不消耗。
- **局外经济**：带出来的东西进仓库，可卖钱、买枪、买护具、买弹药，也能投保（阵亡后七成由走私商捡回）。

## 四张地图 · 天气随机

**每局天气随机，不可选**：晴朗 / 阴天 / 黄昏 / 迷雾 / 雨天 / 雷暴 / 黑夜。夜晚与雨雾雷暴会显著压低能见度，交火距离被大幅压缩。

- **街区**：200m 废城地表，坍塌公寓与弹坑马路。**本图 NPC 中立**——不主动开火，但你先动手会还击，附近同小队也会一起上。
- **秘密实验室**：铁砧地下三层的全封闭设施，36 个房间。**微光环境**，交火距离压到 10~20m，物资密度与稀有度最高，守备最强。
- **港口**：220m 集装箱码头，箱列把视野切成走廊，撤离点在码头前沿。
- **瓦尔登机场**：260m 废弃国际机场，208m 跑道横贯全图。三层航站楼 + 塔台 + 货站 + 货机残骸，物资以**资料与电子产品**为主。

## 联机与排行榜

主菜单有「联机 / 排行榜」页。**创建房间拿房间码**或**输入房间码加入**；部署时若已登录会**自动找房（最多 30 秒）**，超时用 AI 补位。

**每队 4 人**：真人先占位，缺的 AI 补足，中途退出立刻顶替。**玩家同阵营但能互相打死**（友伤）。排行榜显示 **KD / 作战货币 / 仓库价值** 与全服前 12 名。

## 阵营

出击前挑你以哪一方上阵，**两边都能玩**：

- **USEC 联合安保**：合同制雇佣兵，全黑战术装，制式 M4 + P320。
- **PMC 私人军事承包商**：土黄承包商装备，走 G36C / G28 / MP5 一系。

**敌方按地图决定**：街区是德军，实验室/港口/机场是 PMC 精锐。若你选了本图守备方，系统会自动换边。

装备全部由你自己从仓库配——主武器、副武器、**护甲、头盔、耳机、胸挂、背包**、5 个改件槽。护甲只挡胸腹、头盔只挡头部；耳机决定你能听到多远的脚步。

## 核心系统

- **武器库**：57 把枪，从二战兵器（加兰德、STG 44、波波沙、索米、捷克式）到现代制式（M4、AK-74M、HK416、QBZ-95/191、AWM、沙漠之鹰、格洛克 18）。
- **改枪工坊**：瞄具 / 枪口 / 弹匣 / 战术配件 / 照明。照明槽三选一：**战术手电**（按 `G` 开灯，视野变好但你也更醒目）、**激光指示器**（红色光柱与落点，不照亮也不暴露）、**爆闪手电**（按 `G` 连闪 10 次，范围内敌人短暂失能，自己也晃眼）。
- **高低姿态持枪**：滚轮切换。低姿态移动更快，但首发精度与后坐变差。
- **动态难度（ELO）**：打得越好敌人越强；连续阵亡会自动放水。可关掉。
- **战术细节**：部位伤害与断肢、压制与停火、烟雾遮蔽、可破坏墙体。

## 操作

**桌面**：`WASD` 移动 · `Shift` 冲刺 · `C` 蹲 · `Z` 趴 · 左键开火 · 右键 ADS · `R` 换弹 · `1/2` 主副武器 · `3/4/5` 手雷/闪光/烟雾 · `6` 工事 · `G` 手电/激光/爆闪 · `Tab` 背包 · `B` 药品轮盘 · `O` 兵种技能 · `F` 交互 · `H` 医疗 · `K/J` 食物 · `M` 地图 · `N` 夜视 · `P` 计分板 · `X` 架枪 · `V` 近战 · `T/Y/U` 小队 · `Q/E` 探头。

**手机 / 平板**：自动切触屏布局（左摇杆 + 左右手按钮簇），功能与桌面对齐。

**都能自己调**：「游戏设置」可给 35 个动作改键，也能拖动手机端按钮重排并保存。
